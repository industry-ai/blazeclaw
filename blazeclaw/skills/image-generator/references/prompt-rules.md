# 提示词生成规则

## 强制分类

生成提示词前先判断输入词语属于哪一类，严格按对应类别的规则生成。
注意：动宾结构的词语（如读书、开车、做饭等）属于动作短语类，优先按句法结构判断，不要被其中的名词误导。

## 通用约束

1. 只描述主体本身，不添加场景、背景、环境或阴影。
2. 主体必须居中，避免在画面边缘或角落生成任何小元素、装饰、碎片或噪点。
3. 主体本身避免使用纯白色（#ffffff），如果主体有白色部分，使用米白、浅灰或象牙白（如 #f0f0f0、#e8e8e8）代替，纯白（#ffffff）仅用于背景。
4. 最终提示词结尾附加纯白背景标识：`, pure white background（#ffffff）, no gradient, no shadow, clear dark outline around subject, high detail and recognizability, subject itself should not be pure white use off-white or light gray instead, no corner artifacts, no edge decorations, subject centered`

## 按类别约束

### 具体物体
- 只描述物体本身的形状、颜色、材质、关键特征，提取标志性视觉元素
- 严禁出现人、手、动物或任何使用者，即使是该物体通常被人使用的（如书、杯子、笔等），也只画物体本身
- 如果是集合词（动物、植物、水果等），用组合式静物构图，让人看出类别

### 职业身份
- 描述服装、配饰、标志性道具和动作以及场景、面部表情

### 抽象概念
- 情绪/情感类：直接模仿QQ emoji表情包的画风，圆润黄色圆脸，极简扁平设计，只保留脸部不要身体四肢，不要画写实风格的五官或皮肤细节，禁止在图片中生成任何文字、标签或标题
- 非情绪类：用直观的符号或图形表达，避免过于抽象

### 动作短语
- 描述人物姿态、肢体位置、动态效果，提取最典型瞬间

### 场景类
- 描述完整环境，包含多个匹配主题的元素

### 天气类
- 用多个卡通元素组合表达天气现象，不能只画单个物体。根据天气类型选择合适的元素组合，如云层、降水粒子、光线、风等，同类元素要有多个
- 深色描边，纯白背景
- 所有元素必须实心填充（solid filled），不可空心或只有轮廓
- 不添加人物、动物、建筑，只描述天气元素本身

## 反面示例（禁止出现）
- 输入"书"时，禁止生成"a person reading a book"或"someone holding a book"，应只生成"a cartoon book with..."
- 输入"杯子"时，禁止生成"a hand holding a cup"，应只生成"a cartoon cup with..."

## 使用示例

| 输入 | LLM 生成的提示词要点 |
|------|---------------------|
| 桌子 | 矩形桌面、浅棕色木纹、四条直腿、圆角设计 |
| 医生 | 白色长袍、白帽、听诊器、温和微笑 |
| 高兴 | 笑脸表情、弯弯眼睛、黄色圆形、红脸颊 |
| 农场 | 奶牛、小鸡、小羊、小木屋、围栏、谷仓设施 |
| 下雨 | 卡通乌云、雨滴图标、深色描边、纯白背景 |
